# Automation Test Suite

This repository contains **automation tests** for web applications, implemented across multiple frameworks: **Robot Framework, Selenium (Python), Cypress, and Cucumber (BDD)**. The project is structured for easy execution and integration with **CI/CD workflows**.

## 🧪 Test Cases Overview

All frameworks contain the same **100 test scenarios**, covering:

- Homepage & navigation  
- Forms, login/logout, and session handling  
- Tables, filtering, sorting, pagination  
- E-commerce flows: cart, checkout, promo codes  
- API endpoints (GET, POST, PUT, DELETE)  
- Accessibility & UI validation (ARIA, CSS, keyboard)  
- Security tests (XSS, SQL injection)  
- Performance and response time  
- Multi-language and localization support
